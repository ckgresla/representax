* Initial paper
  This section is the finite acceptance program for the first Representax
  systems whitepaper. Establish numerical and scientific equivalence first,
  then demonstrate statistically supported systems improvements on shared
  workloads and capabilities enabled by native JAX execution. Sentence
  Transformers 5.4 and later support text, image, audio, and video, so those are
  shared comparisons rather than absence claims. The differentiating claims are
  JEPA-style learning, integrated evaluation/checkpoint-safe arbitrary sharding,
  and semantics-preserving execution planning. Keep exactly one =NEXT= item.
  Freeze the implementation surface by end of Saturday, 2026-08-22. Arbitrary
  sharding/FSDP and mixed precision are complete. Finish unified AnyModality
  data execution, add the paper's canonical multimodal model panel, then land
  late-interaction, cross/reranking, sparse, reward, and JEPA recipes before the
  distributed evaluation layer. Run the long paired evidence campaign only
  after that implementation freeze. Do not pull general-development work into
  this finite paper path.

** DONE Implement exact native-JAX GradCache as an execution plan for MNR :retrieval:runtime:
  Preserve =MNRTask= and one shared row-level MNR primitive as the sole
  scientific definition.
  GradCache changes only the differentiation schedule: encode fixed-shape chunks
  while retaining the full logical negative population, differentiate the same
  MNR loss with respect to the representations, replay one encoder chunk at a
  time with its cached cotangent, and perform one ordinary optimizer update.

  Start with a small native-JAX transform: =lax.scan= a
  =jax.checkpoint(..., policy=nothing_saveable)= encoder body and let JAX's
  transpose synthesize the reverse replay. Keep query and document chunk sizes
  in =training.grad_cache=, pad only the execution batch with validity masks,
  and derive explicit per-role and per-chunk PRNG keys so stochastic forwards
  replay exactly. Do not add a cached task, a second MNR formula, Python
  backward hooks, or a second optimizer path.

  Treat Pallas as a later representation-kernel optimization, not as the
  GradCache orchestrator: an encoder replay must remain ordinary Equinox/JAX.
  Profile the representation-loss stage first, then consider a tiled Pallas
  custom VJP for normalized similarity, log-sum-exp, and embedding cotangents
  only if it is numerically equivalent and beats XLA. Keep a native-JAX tiled
  fallback for unsupported accelerators.

  Correctness gates compare direct and cached loss, representation cotangents,
  parameter gradients, clipping, optimizer state, and updated parameters across
  asymmetric and symmetric MNR, graded positives, Matryoshka dimensions,
  padding, partial chunks, tied routes, and stochastic dropout. A systems gate
  must show that peak activation memory follows encoder chunk size rather than
  logical batch size.

  Use Sentence Transformers' current =CachedMultipleNegativesRankingLoss= as a
  pinned cross-framework reference and target to beat on the same ModernVBERT
  weights, inputs, pooling, scale, precision, optimizer, and logical negative
  population. Report compilation separately from warmup and steady-state time;
  report OOM boundaries, throughput, and allocator/process peak memory. Relative
  performance produces an explicit warning rather than a flaky correctness
  failure, but this item is complete only when Representax fits every matched
  batch the reference fits and is faster and tighter at steady state. Extend the
  same semantics to global negatives across devices and hosts only afterward.
