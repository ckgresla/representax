#+TITLE: LeJEPA canonical readiness acceptance (2026-08-31)

* Status

Accepted for bounded lifecycle and cross-framework pipeline readiness only.
This is not an ImageNet-1K quality result and no quality-trajectory parity is
claimed.

* Pinned contract

- LeJEPA source: =c293d291ca87cd4fddee9d3fffe4e914c7272052=
- stable-pretraining source: =9aa93f8b6153eebb73f57d4853ccf8a13d848310=
- Exact paper objective: =(1-lambda)*invariance + lambda*per-view-SIGReg=
- Views: 2 global at 224px and 6 local at 98px.
- SIGReg: 1024 slices, 17 knots, maximum frequency 3.0.
- Training projector: =hidden -> 512 -> 2048 -> 2048 -> 512=.
- Public evaluation representation: final-two-block CLS concatenation followed
  by LayerNorm; the projector is not on this path.
- The paper's 98px local choice is authoritative. The pinned stable-pretraining
  Imagenette example's 96px choice is not used. For patch-16, both workers use
  unpadded Conv2d floor semantics, so 98px produces a 6x6 local patch grid.

The bounded GPU model is the exactly matched timm ViT-S/16 profile. The native
model also exposes ViT-B/16 and the paper ViT-L/16 304M-class profile; ViT-L has
a 512-dimensional projector output and 2048-dimensional evaluation output.

* Real data scope

The runner consumed real images from =/raid/datasets/imagenet/train=, which has
1000 extracted class directories. The bounded manifests contain 10 classes and
deterministic disjoint train/probe/test subsets drawn from train images.

Official validation is accepted for quality through the separately reproduced
devkit and archive verification in
=benchmarks/results/imagenet-validation-provenance-20260831/=. This bounded
lifecycle still uses disjoint train subsets and therefore makes no quality claim.
