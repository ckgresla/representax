* Contract

=cross-encoder/ms-marco-MiniLM-L6-v2= revision

reloaded with exact parameter equality. Sentence Transformers also loaded the

* Reference correction

The first paired artifact at =seed-7-v1= is invalid for training comparisons.
Hugging Face Datasets exposed the JSON columns as =document, label, query=, and
=CrossEncoderTrainer= interpreted non-label columns positionally. It therefore
trained on reversed document/query pairs even though explicit evaluation pairs
were correct. The runner now selects =query, document, label= in that order,
with a regression test. The corrected loss trajectories align and the initial
evaluation is exactly equal.
