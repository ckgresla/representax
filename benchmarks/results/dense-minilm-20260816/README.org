#+title: Native all-MiniLM-L6-v2 dense-route acceptance

* Contract

- Sentence Transformers 5.6.1 at =sentence-transformers/all-MiniLM-L6-v2=
  revision =1110a243fdf4706b3f48f1d95db1a4f5529b4d41= versus the native
  Representax BERT, mean-pooling, and normalization module chain.
- FP32 with TF32 disabled upstream and highest JAX matmul precision.
- Batch 16, sequence 128, identical random token IDs and all-valid masks.
- Five warmups and twenty synchronized steady-state forward measurements.
- One RTX 4090; isolated processes run sequentially under a 120-second probe
  deadline. Native compilation has a separate 60-second acceptance ceiling.

* Result

The matched tensor route agrees to =2.83e-7= maximum absolute error,
=1.23e-6= relative L2, and cosine =1.0=. A separate full tokenizer-to-embedding
parity test agrees to =1.08e-7= maximum absolute error.

Representax is =1.312x= faster in steady state: 2.306 ms versus 3.025 ms per
step, or 6,938 versus 5,290 examples per second. Explicit native compilation
takes 15.34 seconds and first execution after compilation takes 3.50 ms.

The native allocator peak is 0.214 GiB versus 0.156 GiB upstream (1.370x), and
the native process peak is 0.678 GiB versus 0.604 GiB (1.123x). Both are
recorded warnings and remain optimization targets, not correctness failures.

See =summary.json= for the machine-readable measurements.
