* Preprocessing finding

Sentence Transformers recognizes this bare Hugging Face artifact as a
structured =message= model and transforms text to
=<|begin_of_text|>User: ...<end_of_utterance>=. Bare AutoTokenizer calls produce
different IDs and a scientifically unmatched job. Representax now uses the
checkpoint's own chat template at the host preprocessing boundary, producing
the same fixed token IDs and attention masks before either model forward.

* Quality boundary

The checkpoint has dropout disabled, so changing the configured seed does not
create three independent scientific training trajectories. Treat these as
systems replications. Representax's mean training loss is =3.8163--3.8168=
versus =3.8147= upstream, while its final nDCG@10 is lower by =0.0112= on
average. This could be an accumulated optimizer/update difference or a shifted
short-horizon learning curve; it is not accepted as quality equivalence yet.
