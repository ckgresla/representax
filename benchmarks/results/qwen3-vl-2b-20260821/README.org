* Numerical acceptance

The tiny multimodal oracle reaches 2.38e-7 maximum hidden-state error,
9.20e-8 relative L2, and 1.0 cosine.  Pixel gradients reach 1.49e-7 maximum
absolute error, 2.65e-7 relative L2, and 1.0 cosine.  The worst parameter
gradient differs by 7.63e-6 absolute and the worst post-AdamW parameter by
1.19e-7 absolute.

A real 32-by-32 image and text produce 28 tokens, 16 flattened vision patches,
and four merged visual tokens.  Against the full upstream 2B FP32 forward, the
native hidden states reach 0.9999998 cosine and 4.62e-4 relative L2; the final
normalized embedding reaches 0.9999999 cosine and 5.06e-4 relative L2.

The native BF16 result differs more from the upstream BF16 result: 0.9979005
hidden-state cosine and 0.9988514 embedding cosine.  The upstream model's own
BF16-versus-FP32 drift is 5.34% relative hidden-state L2 and 3.86% relative
embedding L2, so this is recorded as precision-policy evidence rather than a
model-layout failure.  Tight checkpoint acceptance remains the FP32 contract.
