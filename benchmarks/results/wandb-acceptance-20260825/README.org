* Contract

This is a backend acceptance campaign, not a model-quality or throughput
benchmark. Each task uses a small deterministic fixed-shape synthetic batch and
a compatible native Equinox model. A run is accepted only when every compiled
update is finite and unskipped, the optimizer step reaches 30, and at least one
model parameter changes. Task runs emit =train/loss=,
=train/skipped_update=, =train/gradient_norm=, and =perf/step_seconds=.
Evaluator runs execute the ordinary =EvaluationRunner= and emit their native
=valid/...= metric namespaces.

The two distributed training probes intentionally use a decomposable pointwise
objective so the same global JAX program validates both named sharding plans.
The 2- and 4-device evaluation probes shard an eight-example classification
batch over the data mesh and perform the ordinary exact host reduction.

* Diagnostic findings

The campaign found and fixed one production issue: =EncoderPair.from_encoder()=
placed the same device buffers into both branches. State donation then attempted
to donate an aliased buffer twice. Each branch now receives its own array leaves,
and a GPU regression test proves a donated contrastive-tension update succeeds.

An exploratory direct symmetric-MNR run over a data mesh correctly did /not/
become part of the accepted distributed matrix. Sharding both sides of its
pairwise relation attempted to form =P("data", "data")=. Exact distributed
retrieval already belongs to the GradCache global-negative path, which gathers
compact representations while retaining sharded token payloads. The acceptance
campaign therefore does not misrepresent ordinary decomposable DDP/FSDP as a
drop-in lowering for direct global-negative MNR.

* Reproduction

The executable matrix is =benchmarks/wandb_acceptance.py=. It asserts exact
coverage against the live task registry, never prints the W&B API key, and
writes large local W&B state under =/raid/representax=. Example:

#+begin_src sh
export WANDB_API_KEY=...  # existing W&B credential
GROUP=acceptance-$(date +%Y%m%d-%H%M%S)
ROOT=/raid/representax/wandb-acceptance/$GROUP

python benchmarks/wandb_acceptance.py \\
  --mode tasks --steps 30 --group "$GROUP" \\
  --run-root "$ROOT/runs" --output "$ROOT/tasks.json"
#+end_src

=manifest.json= is the compact machine-readable acceptance record. It retains
every accepted run name, duration, result, and W&B URL; raw W&B state remains
outside Git under =/raid=.
