#+TITLE: Two-process ModernVBERT GradCache acceptance
#+DATE: 2026-08-14

* Result

Accepted process-local exact GradCache across two JAX processes and four RTX
4090s on one physical host.  Each process owns two GPUs and supplies eight query
and eight document token rows for global batch 16.  Query zero's sole positive
is global document eight, which is supplied by the other process.  Both workers
produce the same four-device result and independently compare it with a
full-global-batch one-device oracle.

| Measurement | Process 0 | Process 1 |
|-------------+-----------+-----------|
| Loss absolute difference | 2.3842e-7 | 2.3842e-7 |
| Gradient-norm relative difference | 1.0691e-5 | 1.0691e-5 |
| Updated-model relative L2 | 1.7722e-6 | 1.7722e-6 |
| Updated-model maximum absolute | 1.9964e-5 | 1.9964e-5 |
| Optimizer-state relative L2 | 9.4270e-4 | 9.4270e-4 |
| Optimizer-state cosine | 0.99999956 | 0.99999956 |
| Steady-state median seconds | 0.630294 | 0.630518 |
| Global examples per second | 25.385 | 25.376 |

The larger optimizer-state delta than the one-process device comparison comes
from reassociation of FP32 gradient reductions across the process boundary.
The loss, gradient norm, updated-parameter relative error, and optimizer-state
cosine jointly gate acceptance; both processes agree on the distributed result.

This run proves process-local global-array construction, a cross-process
positive and global negatives, replicated state/key construction, encoder
replay, collectives, and the complete Optax update.  It does not prove physical
inter-host transport, checkpoint publication across hosts, or host-failure
behavior.  Those remain a separate roadmap item.
