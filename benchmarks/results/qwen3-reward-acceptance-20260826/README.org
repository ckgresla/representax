#+TITLE: Qwen3 Reward Lifecycle Acceptance

* Scope
This accepts the paper-frozen =Qwen/Qwen3-0.6B= outcome-reward architecture at
revision =c1899de289a04d12100db370d81485cdf75e47ca=: the native Qwen3 backbone,
an independently initialized scalar sequence-classification head, pairwise
Bradley-Terry training, and Hugging Face-compatible artifacts.

* Evidence
- The public Hub loader resolved the pinned model and its tokenizer assets.
- One compiled pairwise backward pass produced finite gradients in the scalar
  head and backbone; 14 array leaves had nonzero gradients.
- SGD changed the scalar head by a nonzero norm.
- Native export/reload preserved logits exactly.
- Transformers 5.6 loaded all 311 exported tensors as
  =Qwen3ForSequenceClassification= and matched native BF16 logits within
  =0.0078125= maximum absolute difference.
- The processor uses one model-resolved pad token for tokenizer and static-bucket
  padding. This is required for Transformers and native last-token pooling to
  select the same position.

Compact metrics are in =summary.json=. The 1.2 GB exported artifact remains at
=/raid/representax/paper-acceptance/qwen3-reward-0.6b/export=.
