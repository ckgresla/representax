# Paper Assets

`InterVariable.ttf` supplies the figure font; its license is `Inter-LICENSE.txt`.

`representax-mark.pdf` is an exact copy of the author-selected standalone mark
at `docs/assets/representax/representax-mark.pdf` in the repository root.
Its geometry, renderer, and provenance are documented alongside that source.
The paper-local copy keeps manuscript export self-contained. Only the named
preprint includes it in the first-page author row with one explanatory footnote.
The anonymous submission omits both, following the author's final September 25
direction. It is illustrative
branding, not a seventh scientific figure or an empirical learned embedding.
